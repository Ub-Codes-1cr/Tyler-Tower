## 🌟 Overview

**Tyler Tower** is an ultra-modern, high-performance 3D isometric operating canvas and autonomous agentic workspace. It coordinates **300+ AI agents across 26 specialized divisions**, wired through dynamic glowing vector conduits to a central **Ultron Neural Brain Core**.

Everything runs directly in your browser with real-time packet simulations, interactive Kanban boards, calendar scheduling matrices, live multi-timezone clocks, and human-in-the-loop approval workflows.

---

## 🚀 Key Features

- **🌐 3D Autonomous Campus**: 26 specialized departmental pods with 300+ active desks, animated agent citizens, and real-time interaction states.
- **🧠 Ultron Neural Brain Core**: Centered glowing holographic orb routing data packets, tasks, and deliverables across all pods.
- **⚡ Dotted Vector Conduits & Packet Engine**: Real-time glowing visual transmission paths carrying bi-directional task payloads between agents and the brain.
- **🌍 Global Multi-Timezone HUD Clock**: Real-time ticker at top right displaying **IST** (Indian Standard Time UTC+5:30), **UTC** (Universal GMT), **EST** (New York), and local date.
- **🔍 Core 6 Divisions Zoom Control**: Dedicated isometric zoom button framing the central orb and inner 6 core divisions (Marketing, Sales, Emails, Operations, Finance, Delivery) at close perspective.
- **🔄 Auto-Escape Modal Routing**: Seamless mutual exclusivity across all full-screen overlays (Calendar, Brain, Board, Approvals, Connectors, Settings, and Task Drawer).
- **🎥 Studio Camera Mode & Light Theme**: High-contrast, glare-free studio camera mode backdrop alongside the crisp default light canvas.
- **🔒 Standalone & Private**: Operates locally or statically deployed with zero external data leakage.

## 📦 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/Ub-Codes-1cr/Tyler-Tower.git
cd Tyler-Tower/tyler-core
npm install
```

### 2. Build Production Bundle
```bash
npm run build
```

### 3. Launch Local Server
```bash
npm start
# 🏰 Tyler Tower live at http://localhost:4520
```

---

## 🚢 Deployment

### Standalone Static Deployment (Vercel / Netlify / GitHub Pages)
Tyler Tower compiles into a single, self-contained bundle at `dist/command-centre-v2.html` which can be served by any static web server or CDN.

### Docker Deployment
```bash
docker compose up -d
```
